# 실험 실행 프로토콜

## 평가셋 구성

60문항을 사실확인 24, 조건적용 12, 정보추출 12, 함정·거부 12문항으로 구성한다. 사실확인은 자동 채점의 객관성이 높고 양자화 손실을 정량적으로 관찰하는 핵심 유형이므로 표본을 확대한다. 조건적용은 자동점수 외에 블라인드 수동 검토를 수행한다.

## 게이트

1. 설정의 모든 모델 revision을 40자리 SHA로 고정하고 HF API로 직접 검증한다.
2. 고정된 llama.cpp CUDA 런타임에서 GPU 인식을 확인한다.
3. Bllossom 3B Q4와 합성 4문항으로 종단 스모크 테스트를 통과한다.
4. 사용자가 실제 출처에 근거한 60문항과 참조 문서를 직접 작성한다.
5. 평가셋 구조·참조 문서·유형 분포를 검증한다.
6. Bllossom Q4·Q8만 최종 60문항으로 파일럿 실행한다.
7. 파일럿 수정 이력을 남긴 뒤 `dataset.lock.json`으로 평가셋을 동결한다.
8. 동결 후 11개 조합 본 실험을 실행한다.
9. 자동평가 상위 3개 조합의 유형 2 응답 36개를 모델명을 가리고 수동 검토한다.
10. 성능 순위와 라이선스를 반영한 배포 가능 순위를 별도로 보고한다.

## 스모크 완료 기준

- 결과 CSV 한 행이 `success`
- 응답 원문 4개와 유형 1~4 점수 존재
- 모든 문항에 TTFT와 전체 응답 시간 존재
- VRAM 샘플이 한 개 이상이고 최대값이 기록됨
- 512·2048·4096 조건의 PP와 TG 평균·표준편차 존재
- 조합 종료 후 llama-server 프로세스가 남지 않음
- `--resume` 재실행이 성공 조합을 건너뜀
- Markdown·CSV·JSON·SVG 리포트 생성 성공

## 파일럿 완료 기준

- 컨텍스트 초과, 누락 응답, 중복 ID가 모두 0건
- 유형 3 JSON 파싱 실패율이 20% 이하면 통과하며, 초과하면 프롬프트를 재검토
- 유형 4 자동채점 실패 응답을 모두 읽어 키워드 누락과 실제 추론 실패를 구분
- 두 조합 모두 정답 또는 오답인 문항은 자동 삭제하지 않고 모호성과 변별력을 수동 확인
- 수정마다 문항 ID, 수정 전후, 이유, 시각, 영향받은 파일럿 실행을 기록

평가셋을 동결한 이후에는 본 실험이 끝날 때까지 수정하지 않는다.
