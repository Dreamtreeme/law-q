## 다음 실행 명령

실제 평가셋 작성이 끝난 직후:

```powershell
python scripts\validate_dataset.py
python scripts\run_pipeline.py --run-name pilot-bllossom-q4-q8 `
  --only bllossom-3b:Q4_K_M `
  --only bllossom-3b:Q8_0
```

파일럿에서 컨텍스트 초과, JSON 파싱률, 유형 4 거부표현과 문항 변별력을 검토해 필요한 수정 이력을 남긴다. 수정 완료 후 `validate_dataset.py`로 잠금을 다시 만들고, 그 뒤에는 본 실험이 끝날 때까지 평가셋과 문서를 변경하지 않는다.

## 현재 중단 사유

합성 스모크 문항을 실제 법률 평가 데이터로 가장하지 않는다는 원칙에 따라, 에이전트가 60문항을 대신 만들지 않았다. 현재 `eval/questions.jsonl`과 실제 참조 문서를 찾지 못하므로 파일럿과 11개 조합 실행은 시작하지 않는다. 이는 인프라 실패가 아니라 계획에 명시된 사람 검토 데이터의 대기 상태다.
